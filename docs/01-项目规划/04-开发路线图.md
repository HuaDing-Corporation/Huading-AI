## M1 · 内核蒸馏与跑通
- 部署原项目，摸清真实效果与成本
- 抽离生成引擎（pipelines + api_services）为独立服务模块
- FastAPI 后端骨架 + 基础鉴权 + 单租户跑通"主题→成片"
- 接入已有模型 Key，验证 LLM/图像/视频/TTS 全链路
- **里程碑**：API 生成一条视频成功

## M2 · 企业底座 + 控制台 MVP
- 多租户 + 组织/团队/角色权限（RBAC）
- 异步任务队列 + 进度推送 + 对象存储
- UI/UX 设计系统（SOP-4 UI UX Pro Max）
- Next.js 控制台 MVP：工作台、单条生成、任务列表、素材/历史
- 品牌资产库基础版
- **里程碑**：企业用户登录→配品牌→生成→下载

## M3 · 差异化能力
- 批量生产中心（表格驱动批产）
- 团队协作 + 审批流
- 模板中心 + 封面中心
- 数字人口播 / 声音克隆 / 多语种
- **里程碑**：批量、协作化、品牌一致的生产能力

## M4 · 分发与开放
- 发布中心 + 账号矩阵（先接 1–2 平台）
- 数据看板 + 效果回流
- 开放 API / Webhook
- 用量计费与配额
- **里程碑**：生产→分发→数据 闭环商用版

## 贯穿全程的工程纪律（SOP 6–12）
- 每功能完成后 Code Simplifier 整理代码（功能不变）
- Webapp Testing/Playwright 自动测试 + Chrome DevTools 查运行时
- 合并前 Code Review；出 bug/测试失败用 Ralph Loop 循环修复
- 每阶段末用 Claude-mem + Planning-with-files 记录进度与决策（Hermes 负责）
- GitHub 管分支/Issue/PR，MCP 不稳用 gh CLI

## 风险登记（摘要，详见方案设计）
| 风险 | 对策 |
|---|---|
| 开源协议合规 | 编码前出法务确认，保留 NOTICE |
| 模型/算力成本 | 直连 API + 自有 GPU 混合调度，按租户计量 |
| 平台发布风控 | 优先官方开放平台，账号矩阵做频控合规 |
| 前端重写工期 | 后端最大化复用，前端聚焦核心流程 MVP 优先 |
| 生成质量不稳 | 模板 + 提示词工程 + 人工审核环节 |
