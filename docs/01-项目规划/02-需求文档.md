## 1. 目标用户与角色

| 角色 | 画像 | 核心诉求 |
|---|---|---|
| 企业管理员 | 采购/IT/负责人 | 开通团队、分配权限、配置品牌与模型、看用量与成本 |
| 内容运营 | 营销/电商运营 | 批量生产带货/营销视频，套用品牌规范，快速分发 |
| 创作者/编导 | 内容制作 | 单条精修：改文案、换配图/配音、调模板、做封面 |
| 审核员 | 主管/品牌负责人 | 审批成片，把控品牌与合规，再放行发布 |
| 开发者 | 客户技术团队 | 用 API 把视频生产接入自有电商/营销系统 |

---

## 2. 典型使用场景

1. **电商批量带货**：上传商品表（标题/卖点/图） → 批量生成商品短视频 → 审核 → 一键发到多个抖音/视频号账号。
2. **营销选题批产**：输入一批选题 → 自动写文案/标题/话题 → 生成成片 → 数据看板看哪条效果好。
3. **数字人口播矩阵**：配置企业数字人 + 音色 → 文案批量驱动口播 → 多账号分发。
4. **单条精修**：运营对某条不满意 → 在工作台改文案/重配图/换模板/改封面 → 重新合成。
5. **系统集成**：客户电商后台上新商品时，经 API 自动触发生成商品视频并回传。

## 3. 需求分级（建设范围）

> 用户决策（2026-06-05）：以下 P0 / P1 / P2 三档**全部纳入建设范围、都要做**。分档只表示**实现的先后顺序与优先级**，不代表取舍。仅"暂不做"一档排除在本期之外。

### P0（一期 · MVP 必做，最先交付）
- 多租户 + 组织/团队/角色权限（RBAC）
- 单条全自动生成：主题 → 文案 → 配图/视频 → TTS → BGM → 合成 → 下载
- 模型能力接入（复用 api_services：LLM/图像/视频/TTS）
- 异步任务队列 + 实时进度
- Web 控制台：工作台、任务列表、素材/成片管理
- 品牌资产库（基础版）

### P1（二期 · 必做，紧随其后）
- 批量生产中心（表格驱动）
- 团队协作 + 审批流
- 模板中心 + 封面中心
- 数字人口播 / 声音克隆 / 多语种

### P2（三期 · 必做，闭环收尾）
- 发布中心 + 账号矩阵（先接 1–2 个平台）
- 数据看板 + 效果回流
- 开放 API / Webhook
- 用量计费与配额

### 暂不做（本期排除）
- 自研底层视频生成大模型（直接用第三方 API）
- 海外多平台分发
- 复杂非线性专业剪辑（定位是"自动化生产"而非"专业剪辑软件"）

## 4. 非功能性需求
- **性能**：视频生成为长耗时任务，必须异步、可水平扩展；进度可视化。
- **多租户隔离**：起步用共享库 + tenant_id 行级隔离。
- **成本可计量**：每次生成记录模型/token/算力时长，支撑计费与成本核算。
- **安全**：JWT + RBAC；素材/成片对象存储私有读写；密钥服务端托管。
- **可用性**：B 端控制台体验需达到商用标准（区别于原 Streamlit Demo）。
- **合规**：保留开源 NOTICE；发布功能遵守各平台风控与频控。

## 6. 需求澄清结论（SOP 第 2 步已确认，2026-06-05）
1. **分发平台**：抖音、小红书、视频号、B 站均接入；优先级 抖音 / 小红书 > 视频号 / B 站。
2. **计费模式**：**套餐制**（按年/月订阅分档，含月度生成额度）。
3. **交付形态**：**仅 SaaS**（统一云端多租户，暂不做私有化）。
4. **数字人/声音克隆**：归 P1（二期），随全量建设计划推进。
5. **首个目标行业**：**电商带货**——模板库、话术库、商品视频流水线优先做电商。
