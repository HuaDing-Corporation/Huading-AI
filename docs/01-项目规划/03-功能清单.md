# 功能清单

> 版本 v0.1｜日期 2026-06-05｜对应 SOP 第 1 步
> 优先级：P0=MVP 必做，P1=二期，P2=三期。标注「蒸馏」表示可复用 Pixelle-Video 资产改造，「新建」表示华鼎全新。

---

## A. 内容生成（引擎核心）

| 功能 | 优先级 | 来源 | 说明 |
|---|---|---|---|
| 主题→文案/脚本生成 | P0 | 蒸馏 | 复用 prompts/content_narration、topic_narration |
| 文案仿写（喂对标风格） | P1 | 新建 | 输入对标账号文案，仿写风格 |
| 标题 & 话题生成 | P0 | 蒸馏+增强 | 复用 title_generation，加平台热点话题 |
| AI 配图生成 | P0 | 蒸馏 | image_dashscope/gpt/seedream |
| AI 视频生成 | P0 | 蒸馏 | video_dashscope/kling/seedance、图生视频 |
| 语音合成 TTS | P0 | 蒸馏 | edge-tts / index-tts，多语种 |
| 声音克隆 | P1 | 蒸馏 | 企业音色库 |
| 数字人口播 | P1 | 蒸馏 | 原项目扩展模块 |
| 动作迁移 | P2 | 蒸馏 | 原项目扩展模块 |
| 背景音乐 BGM | P0 | 蒸馏 | 企业授权曲库 |
| 自定义素材分析生成脚本 | P1 | 蒸馏 | 上传图/视频，VLM 反推生成脚本 |

## MVP（P0）范围速览
多租户底座 + 单条全自动生成（文案→配图/视频→TTS→BGM→合成→封面→下载）+ Web 控制台 + 模型能力层 + 异步队列 + 品牌库基础 + 素材/历史管理。
**目标：企业用户能登录、配品牌、生成并下载一条合格视频。**
