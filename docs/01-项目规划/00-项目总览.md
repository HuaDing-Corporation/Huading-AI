# 华鼎 AI 全自动短视频引擎 · 项目总览

> 版本 v0.1（规划阶段初稿）｜日期 2026-06-05｜负责人：Cowork（总指挥）
> 本文件是项目的总入口，对应 SOP 第 1 步（Planning-with-files）。其余规划文件见同目录 01-04。

---

## 1. 项目愿景

把开源项目 **Pixelle-Video**（阿里 AIDC，Apache-2.0）蒸馏、重构为华鼎公司自有的 **面向企业（B 端）的 AI 短视频批量生产中台**：企业用户输入主题 / 商品 / 脚本，即可批量产出符合品牌规范、可直接分发到各平台的成片，并支持团队协作、数据回流与 API 接入。

一句话定位：**「企业级 AI 短视频工厂」——把视频生产变成可批量、可协作、可计量、可集成的标准化流水线。**

---

## 2. 关键决策（已与用户确认）

| 项 | 决策 |
|---|---|
| 蒸馏对象 | Pixelle-Video（Apache-2.0，可商用闭源改名，须保留 NOTICE/版权） |
| 改造深度 | **重度差异化**（不是换皮，叠加企业自有能力） |
| 目标用户 | **B 端企业客户**（营销/电商/MCN/品牌团队） |
| 起步方式 | 先做规划与方案设计，不直接写码 |
| 竞品对标 | 国内为主（即梦/剪映、可灵、腾讯智影等） |
| 资源就绪度 | GitHub 仓库 ✅、模型 API Key ✅、GPU 算力 ✅（无需排资源准备阶段） |
| 协作机制 | 人工传达：Cowork 出任务包 → 用户转交 Agent → Agent 回执 → 用户转回 Cowork |

## 4. 标准作业流程（SOP）

## 5. 协作协议（任务包 / 回执）

**任务包**（Cowork → 用户 → Agent）字段：
编号、指派给、阶段、目标、背景、要求、用到的 Skill、交付物、验收标准、依赖。

**回执**（Agent → 用户 → Cowork）字段：
编号、来自、状态（完成/部分/受阻）、产出、关键决策与变更、遗留问题与风险、建议下一步。
