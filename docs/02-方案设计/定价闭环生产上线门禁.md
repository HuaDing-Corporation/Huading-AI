本阶段只构建和测试命令，**没有执行生产注册**。任何阻断项都必须立即停止发布；禁止用手工改数据库代替迁移、审计或注册命令。

## 3. 生产只读审计

### 3.1 唯一允许的审计入口

在已明确指向目标生产环境、且已完成第 5 节第 1–4 步的受控执行终端中运行：

```powershell
Push-Location backend
uv run python scripts/ops/pricing_closure_readiness.py audit
$auditExit = $LASTEXITCODE
Pop-Location
if ($auditExit -ne 0) { throw "Pricing closure readiness audit blocked release" }
```

`audit` 是只读命令。执行人必须保存完整输出、执行时间、目标生产 revision 和审批单号。不得把默认、本地、测试或共享数据库结果冒充生产证据；不得在文档、日志摘要或聊天中粘贴密码、连接串或生产官方/provider ID。

### 3.2 当前阻断

最新的全新隔离只读审计以 exit 2 结束，且只有一个阻断：

| 阻断码 | 含义 | 解除责任人 | 解除标准 |
|---|---|---|---|
| `OFFICIAL_DOUBAO_CONFIG_MISSING` | 官方豆包配置尚未满足上线不变量 | 平台负责人 + 发布执行人 | 平台负责人在安全审批附件中签署准确官方 ID 清单；生产只读快照完成；预部署 `audit` exit 0 且无 blocker |

在阻断解除前，不得部署、迁移、执行 `register-official`、启用客户路由或改变工作台上线状态。

## 4. 一票否决条件

出现以下任一情况，执行人必须停止发布、保留现场并升级审批人：

- 只读审计非零退出，或出现任何 blocker/warning 被审批规则定义为阻断。
- 生产 revision、ENV、费率、租户覆盖项与已审批内容不一致。
- Wallet、BrandVoice、ProviderConfig 或官方槽位快照不完整，或导出范围遗漏 inactive 数据。
- 平台负责人未签署准确官方 ID 清单，或执行时清单与签署版本不一致。
- 历史记录的 `owner_user_id`、`activated_at`、`expires_at` 任一不再为 null。
- 后端、前端与迁移不能作为同一变更窗口共同发布。
- 客户豆包路由未保持 fail closed，或 registry/config/inventory 三者不一致。
- 注册命令已被执行过、执行次数无法证明，或输入不是获签的 `ENGINE_DOUBAO_OFFICIAL_VOICE_IDS`。
- 任一 smoke test、账务守恒、幂等、退款、恢复或对账检查失败。
- 有人提议用手工数据库编辑、临时脚本、跳过检查或重跑掩盖失败来解除阻断。
- 缺少独立、明确、可追溯的生产审批。

### 5.1 注册命令边界

只有第 1–7 步全部完成并获批后，发布执行人才可在受控生产终端运行：


命令输入只能来自已签署的 `ENGINE_DOUBAO_OFFICIAL_VOICE_IDS`。不得在命令行、本文或普通发布记录中展开其值；不得补充、猜测或改写任何官方/provider ID。该命令只允许执行一次，失败后也不得自行重跑，必须停止并由审批人重新裁决。

## 6. 业务闭环验收

生产 smoke 必须覆盖完整资金生命周期，不得只验证页面成功提示：

1. `estimate` 只读且返回权威报价；报价失败时前端保持关闭，不能继续提交。
2. `reserve` 成功后才允许调用供应商；提交同时具备报价与幂等计费头。
3. 成功路径完成 `settle`，未使用额度完成 `release`。
4. 人工品牌音色订单分别验证 fulfill 与 reject；退款只发生一次。
5. 相同幂等键重复请求不重复扣款、不重复注册、不重复交付。
6. 未知网络结果通过权威查询恢复，不向客户声称未经确认的释放或成功。
7. 每个终态均满足 `requested = settled + released` 且 `held_credits = 0`。
8. 最终对账 Wallet、UsageRecord、供应商成本和业务产物；任一差异均阻断上线。
