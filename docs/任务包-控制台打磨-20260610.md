## 任务包 A — 后端：对象存储 + 成片播放 ｜ `#M2-STORAGE-BE`

- **负责**：Codex A（后端）
- **分支**：`feature/video-storage-minio`（⚠️ Codex A 沙箱不能建分支 → **用户先建好**）
- **依赖**：无（先落地，定义契约给前端）

### 范围（In scope）
1. **对象存储抽象层**（boto3，S3 兼容；MinIO 走 path-style + 签名 v4）。
2. **worker 出片后上传**：moviepy 渲染完 → 上传 mp4（及封面/缩略图）到 bucket，按租户隔离 key；写回 DB 的 `storage_key`，替换 `file://` 路径；标记 done。大文件用 multipart。
3. **Alembic 迁移**：`videos` 表新增 `storage_bucket / storage_key / thumbnail_key / content_type / size_bytes / duration_sec`（均可空，保留旧本地路径列向后兼容）。
4. **租户级接口**（同时清掉"视频列表持久化"backlog）：
   - `GET /api/v1/videos`（租户作用域列表，分页）
   - `GET /api/v1/videos/{id}`（详情；跨租户/不存在统一返回 **404**，防枚举）
5. **预签名 URL**：仅对调用方租户拥有的视频生成；`playback_url`（GET）、`download_url`（GET + `response-content-disposition=attachment`）、`thumbnail_url`；TTL 默认 3600s。
6. **compose 加 MinIO**：minio 服务 + 初始化容器建 bucket 并设为私有；backend/worker 注入 `ENGINE_S3_*`。

### 接口契约（前端按此对接，务必稳定）
```jsonc
// GET /api/v1/videos  与  GET /api/v1/videos/{id}（items 内单项）
{
  "id": "uuid",
  "title": "string",
  "prompt": "string",
  "mode": "static | seedance_t2v | seedance_i2v",
  "status": "queued | running | done | failed",
  "progress": 0,                  // 0-100
  "created_at": "ISO8601",
  "duration_sec": 12.5,           // 可空
  "thumbnail_url": "presigned|null",
  "playback_url":  "presigned|null",   // done 前为 null
  "download_url":  "presigned|null",   // attachment，done 前为 null
  "error": "string|null"
}
// 列表外层：{ "items": [...], "next_cursor": "string|null" }
```

### Key 布局
```
s3://{ENGINE_S3_BUCKET}/tenants/{tenant_id}/videos/{video_id}/output.mp4
                                                          .../thumbnail.jpg
```

### 安全要点（审查会盯）
- 预签名只对**本租户拥有**的视频签发；跨租户 id → 404（不泄存在性，防 IDOR）。
- bucket **私有**，绝不开 public-read；访问全靠预签名 + 短 TTL。
- 不在日志/响应里回显密钥或原始 key；不把内部 endpoint 暴露给前端。
- 签名用 v4，addressing=path-style。

### ⚠️ MinIO 预签名主机坑（最容易翻车）
- 内部读写用 `ENGINE_S3_ENDPOINT=http://minio:9000`（compose 网内）。
- **给浏览器的预签名 URL 必须用 `ENGINE_S3_PUBLIC_ENDPOINT=http://localhost:9000`**——否则浏览器解析不了 `minio` 主机名。做法：用一个指向 public endpoint 的 boto3 client 专门生成预签名；内部存取另用 internal client（共享同一组凭据）。
- `<video>` 拖动进度（seek）靠 S3 Range，预签名 GET 原生支持，无需额外改造；但**用 fetch 触发下载或跨域时给 bucket 配 CORS allow `http://localhost:3000`**。

### 验收标准（AC）
- worker 出片后成片在 MinIO 可见，DB 记录 `storage_key`，不再有 `file://`。
- `GET /api/v1/videos` 只返回本租户视频；`playback_url/download_url` done 后可用、可播、可下载、可 seek。
- 跨租户取他人视频 id → 404。
- Alembic up/down 干净。

### 回执
分支 + commit/PR 号、迁移文件名、改动文件清单、新增 env 列表、跨租户 404 的自测说明。

## 任务包 B — 前端：布局修复 + 播放器 + 返回 + 列表持久化 ｜ `#M2-CONSOLE-POLISH-FE`

- **负责**：Claude Code（`claude-code` worktree）
- **分支**：`feature/console-polish`
- **依赖**：本分支**从 `develop` 切出**（#15 已合入 develop，是基线）。播放器/下载/列表 hydrate 依赖任务包 A 的新契约（在 #17，未合）；可直接照 A 的契约 JSON 开发。**布局修复(B0/B1/B2)独立，可立即并行**。
- **⚠️ 合并策略（Codex B #M2-CONSOLE-POLISH-RV 打回 #17 的处理）**：#17 把 API 契约升级为新版（`status: queued/running/done/failed`、`playback_url/download_url`），但 develop 现有前端（#15）还在用旧契约（`SUCCESS/PROGRESS`、`video_url`）→ 单独合 #17 会让"完成"任务回退成"排队中"、且拿不到播放 URL。**故 #17 不单独合**；本包必须先做 **B-契约** 迁移，再让 **#17 与本 console-polish PR 一起合**（develop 始终不破）。

### 范围（In scope）

**B0 — object URL 生命周期清理（Codex B 在 #M2-SEEDANCE-P2-FE-RV 标的 P2）**
- 现状：`new-video-card.tsx` 仅在 `clearImage()`(≈L74) 与替换图片(≈L98) 时 `revokeObjectURL`，**组件卸载时不兜底**——用户带着预览离开控制台会漏 object URL。
- 改法（最小、安全，不动现有 clear/替换逻辑，靠 ref 只在卸载时收尾）：
  ```tsx
  const previewUrlRef = useRef<string | null>(null);
  useEffect(() => { previewUrlRef.current = imagePreview; }, [imagePreview]);
  useEffect(() => () => {
    if (previewUrlRef.current) URL.revokeObjectURL(previewUrlRef.current);
  }, []);
  ```
- 卸载时正常流程不会再触发 clear/替换，故无重复 revoke；即便重复，revoke 已失效 URL 也是 no-op，安全。
- AC：带图片预览离开/重新进入控制台无 object URL 泄漏（DevTools Memory 或手动检查）。

**B1 — 修"新建视频"布局（病根 1/2/3）**
- 三列栅格 `[侧边栏 | 表单 ~320px | 生成任务 flex-1]`；表单列 `min-width: 260px`，删掉那条 ~90px 窄条；窄屏堆叠。
- **生成模式分段控件**：容器 `flex`，每段 `flex:1`，标签 `white-space:nowrap`；标签缩短为 `静态 / 文生 / 图生`（Seedance 以小 badge 或 tooltip 体现），消除重叠。
- **所有 chip**（视觉模板、语音/尺寸）：`inline-flex` + padding + `white-space:nowrap`，去掉触发逐字竖排的 `word-break:break-all`；chip 组 `flex-wrap`。
- **生成视频按钮**：`width:100%`，文字横排。
- 重新平衡留白：生成任务卡给 `max-width`，右侧空白补**空状态/最近列表**，别留大片白。

**B2 — 返回导航（病根 4）**
- 控制台左上加返回（面包屑 `工作台 / 返回项目` 或返回按钮），路由回上一页/首页，沿用鎏金设计系统样式。

**B-契约 — 前端对齐后端新契约（Codex B 在 #M2-CONSOLE-POLISH-RV 标的 P1，B3/B4 的前提）**
- `videos.ts`(≈L9)：类型从旧 `VideoTaskStatus`(`SUCCESS/PROGRESS/...` + `video_url`) 改为后端 `VideoRead`：`status: 'queued'|'running'|'done'|'failed'`，字段 `playback_url`/`download_url`/`thumbnail_url`/`duration_sec`，去掉 `video_url`。
- `tasks-context.tsx`(≈L60)：reconcile/poll **不要把 `done` 当默认 queued**——按新枚举映射状态，并保留 `playback_url`；SSE 实时更新与 `GET /api/v1/videos` 结果**按 id 合并**，避免"完成→排队中"回退。
- `task-list.tsx`(≈L62)：把外链"查看成片"替换为 B3 的内嵌 `<video>` 播放器 + 下载，读取新字段。
- AC：SSE 结束后 reconcile/poll **不回退**、能拿到 `playback_url`；状态枚举与后端一致。

**B3 — 内嵌播放器 + 下载（病根 5）**
- 任务卡 `status=done` 且有 `playback_url` → 渲染 `<video controls preload="metadata" poster={thumbnail_url} src={playback_url}>` + **下载**按钮（`<a href={download_url} download>`）。
- `running` 显示进度条；`failed` 显示失败态。
- `<video> onError`（URL 可能过期）→ 重新拉一次 `GET /api/v1/videos/{id}` 刷新预签名 URL，重试一次。

**B4 — 列表持久化（hydrate）**
- 挂载时 `GET /api/v1/videos` 拉本租户列表填充"生成任务"；按 id 合并 SSE 实时更新；无数据给空状态。**刷新页面不丢历史。**

### 验收标准（AC）
- "新建视频"内无任何重叠/竖排文字，标签全横排可读；三个模式 pill 清晰可选。
- 返回按钮可见且可用。
- 完成的任务卡内嵌播放器**能播、能拖动进度**；下载按钮能下 mp4。
- 刷新页面后历史视频仍在列表。
- 窄屏/移动端列堆叠、无溢出。

### 回执
分支 + commit/PR 号、改动组件清单、修复前后截图（重点：模式 pill、chip 横排、播放器、返回）、对接的接口字段。

## 附录 — 环境 / compose / 坑清单（用户 e2e 用）

### `infra/.env` 新增
```env
# 对象存储（MinIO）
ENGINE_S3_ENDPOINT=http://minio:9000          # 内部读写（compose 网内）
ENGINE_S3_PUBLIC_ENDPOINT=http://localhost:9000  # 浏览器预签名主机（关键）
ENGINE_S3_ACCESS_KEY=huading
ENGINE_S3_SECRET_KEY=<32+随机>
ENGINE_S3_BUCKET=huading-videos
ENGINE_S3_REGION=us-east-1
ENGINE_S3_SECURE=false
ENGINE_S3_PRESIGN_TTL=3600
# MinIO root（compose 用）
MINIO_ROOT_USER=huading
MINIO_ROOT_PASSWORD=<同上或独立>
```
保持不变：`ENGINE_SEEDANCE_*`（注意是这个前缀，不是 SEEDANCE_）、`BACKEND_PORT=8080`、`NEXT_PUBLIC_API_BASE_URL=http://localhost:8080`、LLM 仍 DeepSeek（`ENGINE_LLM_`）、`JWT_SECRET_KEY`。

### 坑清单
- **MinIO 预签名主机**：浏览器 URL 必须用 `localhost:9000`，内部用 `minio:9000`，否则播放/下载 404 解析失败。
- **端口**：9000/9001 别被 winnat 占；被占就换并同步 `ENGINE_S3_PUBLIC_ENDPOINT`。8000 仍被占 → 后端走 8080；起全栈前确认 3000 空（node 占了 taskkill）。
- **bucket 私有 + CORS**：下载/跨域给 bucket 配 CORS allow `http://localhost:3000`。
- **Docker**：Agent 跑不了 Docker，全栈 e2e 由用户跑。
- **生产凭据（Codex B P2）**：compose 默认 MinIO 凭据是已知占位值、bucket 私有，仅适合本地；**生产环境必须覆盖 `MINIO_ROOT_*` / `ENGINE_S3_*`**。
- **DB 约束（Codex B P2，记 M3）**：迁移新增 `video_mode/progress/created_at` 为 nullable，模型按默认值用；M3 可补 NOT NULL/默认值收紧。
