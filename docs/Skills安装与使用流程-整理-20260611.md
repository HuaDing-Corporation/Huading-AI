## 一、使用顺序（来自 001 总纲，九阶段）

1. **调研规划**：Open Notebook → Planning-with-files → Claude-mem
2. **需求拆解 / 项目管理**：Superpowers → Gstack
3. **UI/UX 与前端设计**：UI UX Pro Max → Frontend-design
4. **正式开发**：Superpowers → Gstack → GitHub
5. **代码整理**：Code Simplifier
6. **浏览器测试调试**：Webapp Testing / Playwright → Chrome DevTools MCP
7. **代码审查提交**：Code Review → GitHub
8. **反复修复疑难**：Ralph Loop
9. **沉淀项目记忆**：Claude-mem → Planning-with-files

## 二、逐项安装来源与命令

### A. 来自 `claude-plugins-official` marketplace（直接 `/plugin install`）
> 若该 marketplace 尚未添加，先在 Claude Code 跑一次 `/plugin`（打开插件管理器）确认它在列；这些命令文档里都假设它已添加。

| Skill | 安装命令 |
|---|---|
| **Frontend-design**（007） | `/plugin install frontend-design@claude-plugins-official` |
| **GitHub**（008，官方 MCP） | `/plugin install github@claude-plugins-official` |
| **Code Simplifier**（010） | `/plugin install code-simplifier@claude-plugins-official` |
| **Code Review**（013） | `/plugin install code-review@claude-plugins-official` |
| **Ralph Loop**（014） | `/plugin install ralph-loop@claude-plugins-official` |
| **Webapp Testing**（011，Playwright，skill 名 `webapp-testing`） | 文档未在开头明列命令；按同一 marketplace 套路应为 `/plugin install webapp-testing@claude-plugins-official`（**以文档 011 为准**） |

安装后：`/reload-plugins` 重载，`/plugin` 看列表确认 Installed。

### B. 独立 marketplace / GitHub 仓库
| Skill | GitHub 来源 | 安装方式 |
|---|---|---|
| **Superpowers**（006） | `github.com/obra/superpowers` | 装到 Claude Code；命令 `/brainstorm`、`/write-plan`、`/execute-plan`、`/using-superpowers` |
| **Gstack**（002） | `github.com/garrytan/gstack` | 命令含 `/plan-ceo-review`、`/plan-eng-review`、`/review`、`/design-review` 等多角色 |
| **Planning-with-files**（003） | `github.com/OthmanAdi/planning-with-files` | `/plugin` 或拷到 `~/.claude/skills`；命令 `/planning-with-files:plan` / `:status` / `:start`（详见仓库 `docs/installation.md`） |
| **UI UX Pro Max**（012） | `nextlevelbuilder/ui-ux-pro-max-skill` | `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill` → `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`（或 CLI：`npm i -g uipro-cli` → `uipro init --ai claude`） |

### C. MCP（用 `claude mcp add`，不是 `/plugin`）
| MCP | 安装命令 |
|---|---|
| **Chrome DevTools**（009） | `claude mcp add chrome-devtools --scope user -- npx chrome-devtools-mcp@latest`，然后 `claude mcp list` / Claude Code 里 `/mcp` 确认 |

### D. 独立应用（Docker，不是插件）
| 应用 | GitHub 来源 | 启动 |
|---|---|---|
| **Open Notebook**（005，研究助手） | `github.com/lfnovo/open-notebook` | 装在 `C:\AI\open-notebook`；`docker compose up -d` → `localhost:8502`（需 Docker Desktop） |
| **Claude-mem**（004，长期记忆） | `github.com/thedotmack/claude-mem` | 需 Bun + uv；worker 手动起：`npx claude-mem start`；可选预读代码库 `/learn-codebase`。注意 Auto-memory 默认被环境变量 `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` 禁用 |
