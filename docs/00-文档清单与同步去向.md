# 文档清单与同步去向（两台机对齐用）

> 目标：Windows 与 Mac(M3) 两台机文档一致。规则很简单——
> **代码/进度走 Git；文档默认走飞书；密钥只放飞书私有、绝不进 Git。**

## 推荐做法（最省心）
1. 在**飞书云盘**建一个「华鼎项目」文件夹，把下面【飞书】那批全传进去 → 两台机都从飞书看/下载。
2. **密钥** `infra/.env` 的副本（`huading-infra.env`）放飞书同一文件夹下的「密钥-私有」子目录，**绝不进 git、绝不外发**。
3. 代码、计划(Planning-with-files 写进 repo 的 markdown)、GitHub Issue/PR → 本来就靠 git 两机同步。

> 想更自动（可选，等你顺手）：把【可进 Git】那批 commit 进仓库 `/docs`、脚本进 `/scripts`，以后随 git 自动同步、Agent 也能直接读、连飞书上传都省。要不要这么做随你，不强求。

- **要跑的代码、要让 Agent 读的任务包** → 进 git。
